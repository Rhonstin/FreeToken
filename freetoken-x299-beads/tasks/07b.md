# 07b. Оптимізувати expert-cache/KV/PLE memory split — виконання та приймання

Версія плану: 2. Стара задача: 07.

## Вхідні умови

bytes/expert, usable KV tokens, graph/scratch peak, misses per layer.

## Контракт

Accounting includes scales/alphas і dummy pages; memory headroom separately from theoretical capacity.

## Покрокове виконання

1. Прочитати завершений contract задачі a та перевірити evidence SHA/hardware fingerprint.
2. Виконати базову діагностику/experiment за contract. Для optimization без bottleneck evidence завершити no-change ADR, не писати speculative code.
3. Змінити лише узгоджені interfaces/files. Інший subsystem виявився необхідним — створити blocker bead, не розширювати scope мовчки.
4. Запустити positive і negative fixtures із задачі a та релевантні існуючі regression tests. Для bug спочатку red на baseline, потім green.
5. Запустити paired uninstrumented A/B за RUNBOOK.md; raw rows не редагувати. OOM/error/skipped окремо, а не в mean.
6. Перевірити rollback до baseline/default і повторний запуск. Заповнити result.json, no-change ADR за потреби.
7. Закрити bead тільки після GATES.md. У handoff вказати exact command, exit code, artifact SHA, limitations і actual next ready ID.

## Обов’язкові негативні сценарії

## Stop conditions

Підібраний preset повинен пережити prefill declared max context. OOM не повторювати нескінченно; candidate rejected.

## Детальна постановка батьківської задачі

# 07. Оптимізувати expert-cache/KV/PLE memory split

## Робота

Побудувати miss-rate/latency curve за GPU expert slots при fixed контексті. Порівняти moe-cache-auto з manual budget; не резервувати 128K для 16K workload. Врахувати graph buffers, QSA/GDN state, MTP disabled baseline, PLE staging і піки prefill. Перевірити cache warmup/reset після runtime rebuild.

## Критерії приймання

Budget frontier містить VRAM peak, exact bytes per expert slot, cache misses та TPOT. Найкраща конфігурація не OOM на declared prefill. Не прирівнювати KV savings до speedup; freed VRAM спрямовується в experts лише коли це вигідно.
