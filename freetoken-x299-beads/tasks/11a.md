# 11a. Зменшити overhead expert transfers на PCIe 3.0 — контракт і fixtures

Версія плану: 2. Стара задача: 11.

## Вхідні умови

source/destination strides, actual quant banks, copy plan and event ownership.

## Контракт

Explicit producer-ready/consumer-done ownership; separate stream ordering; raw byte equality fixtures.

## Покрокове виконання

1. Зібрати inputs нижче; невідомі поля залишити null із reason, не підставляти guesses.
2. Прочитати поточні symbols у вказаних файлах; порівняти з baseline SHA. За drift оновити contract, не застосовувати старі hunks.
3. Створити contract.json за CONTRACTS.md: scope, baseline, fields, invariants, cases, commands, expected outcomes.
4. Описати кожний negative case як fixture: given/when/then, exact assertions; valid/invalid cases розділити.
5. Зібрати baseline/reproduction evidence до production code edit. Hardware відсутній — заблокувати лише необхідну hardware частину.
6. Зафіксувати bounded candidate set, numerical tolerances і performance metric до вимірів. Передати артефакти задачі b.

## Обов’язкові негативні сценарії

- small mixed copies.
- K/V-like bank scales absent.
- offset >2^31.
- zero misses.
- buffer reused before event.
- cancellation.

## Stop conditions

Не вилучати workaround без reproduction and regression. H2D bytes рахує metadata/scales і payload.

## Артефакти

У `evidence/x299/11a/`: contract.json, commands.json, result.json і raw logs. Для a result.outcome=contract_ready; для b implemented/no_change/blocked. Actual raw measurement paths мають існувати. Усі статуси в Beads.

## Критерій закриття цієї фази

## Детальна постановка батьківської задачі

# 11. Зменшити overhead expert transfers на PCIe 3.0

## Робота

Профілювати copy_missing і fused gather на типових expert sizes. Existing small-copy cudaMemcpyBatchAsync workaround не видаляти. Порівняти коалесинг metadata/copies, persistent staging, alignment і streams без зайвого full-layer H2D у decode. Pipeline лише коли потрібні expert IDs уже відомі; future-token routing не припускати.

## Критерії приймання

Host blocking/transfer latency зменшені на реальному PCIe3 x16 без regression small-copy path. Перевірені quantized bank offsets/scales, stream/event lifetime, graph replay і cancellation. Не деквантувати весь expert bank до H2D за замовчуванням.
