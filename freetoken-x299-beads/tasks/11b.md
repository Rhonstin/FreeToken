# 11b. Зменшити overhead expert transfers на PCIe 3.0 — виконання та приймання

Версія плану: 2. Стара задача: 11.

## Вхідні умови

source/destination strides, actual quant banks, copy plan and event ownership.

## Контракт

Explicit producer-ready/consumer-done ownership; separate stream ordering; raw byte equality fixtures.

## Покрокове виконання

1. Прочитати завершений contract задачі a та перевірити evidence SHA/hardware fingerprint.
2. Виконати базову діагностику/experiment за contract. Для optimization без bottleneck evidence завершити no-change ADR, не писати speculative code.
3. Змінити лише узгоджені interfaces/files. Інший subsystem виявився необхідним — створити blocker bead, не розширювати scope мовчки.
4. Запустити positive і negative fixtures із задачі a та релевантні існуючі regression tests. Для bug спочатку red на baseline, потім green.
5. Запустити paired uninstrumented A/B за RUNBOOK.md; raw rows не редагувати. OOM/error/skipped окремо, а не в mean.
6. Перевірити rollback до baseline/default і повторний запуск. Заповнити result.json, no-change ADR за потреби.
7. Закрити bead тільки після GATES.md. У handoff вказати exact command, exit code, artifact SHA, limitations і actual next ready ID.

## Обов’язкові негативні сценарії

- small mixed copies.
- K/V-like bank scales absent.
- offset >2^31.
- zero misses.
- buffer reused before event.
- cancellation.

## Stop conditions

Не вилучати workaround без reproduction and regression. H2D bytes рахує metadata/scales і payload.

## Артефакти

У `evidence/x299/11b/`: contract.json, commands.json, result.json і raw logs. Для a result.outcome=contract_ready; для b implemented/no_change/blocked. Actual raw measurement paths мають існувати. Усі статуси в Beads.

## Критерій закриття цієї фази

## Детальна постановка батьківської задачі

# 11. Зменшити overhead expert transfers на PCIe 3.0

## Робота

Профілювати copy_missing і fused gather на типових expert sizes. Existing small-copy cudaMemcpyBatchAsync workaround не видаляти. Порівняти коалесинг metadata/copies, persistent staging, alignment і streams без зайвого full-layer H2D у decode. Pipeline лише коли потрібні expert IDs уже відомі; future-token routing не припускати.

## Критерії приймання

Host blocking/transfer latency зменшені на реальному PCIe3 x16 без regression small-copy path. Перевірені quantized bank offsets/scales, stream/event lifetime, graph replay і cancellation. Не деквантувати весь expert bank до H2D за замовчуванням.
