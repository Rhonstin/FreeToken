## Детальна постановка батьківської задачі

# 12. Bounded RAM row cache для дискового PLE

## Робота

C++ PLE store deduplicates rows within fill, але не кешує між fill. Спочатку trace row reuse та disk latency. Якщо є locality — bounded exact-row cache із checkpoint/extent identity; capacity від реально вільної RAM, не від усіх 104 GB. Порівняти disk, disk+cache і full pinned лише якщо fit. Cache packed source bytes для збереження decoder semantics.

## Критерії приймання

Repeated rows byte-identical, checkpoint change invalidates cache, deterministic eviction і hard memory cap. Miss/read error не підміняється нулями. Cold/warm/random-code workloads показують hit rate і TPOT; без gain код не вмикається. SSD/NVMe на машині не припускається.
