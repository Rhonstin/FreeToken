## Детальна постановка батьківської задачі

# 18. Спільний tuning KV quantization та expert residency

## Робота

Перевикористати реалізацію і acceptance попереднього KV плану; у поточному tree вже є FP8/NVFP4 kernels. Порівняти BF16/FP8/NVFP4 спершу fixed expert slots для isolated dequant cost, потім optimized slots. Context buckets 4K/16K/32K/64K. Reuse жодного неперевіреного статусу: закриті GPU gates мають hardware evidence.

## Критерії приймання

Визначено, коли менший KV знижує PCIe misses і коли restore cost з’їдає виграш. Quality gates попереднього плану збережені; PPL not run не перетворений на passed. Немає дублювання codec implementation задач; optional dependency мапиться на actual Beads IDs вручну.
