## Детальна постановка батьківської задачі

# 19. Prefill і multi-turn latency без шкоди decode

## Робота

Окремо підібрати chunked prefill, existing overlap і --moe-prefill-hit-d2d для PCIe3. Виміряти TTFT нового запиту під час активного decode; concurrency 1 основний preset, 2/4 secondary. Prefix/hybrid state reuse перевірити на agentic context edits. Уникати capacity/large-batch settings, що погіршують single-user TPOT.

## Критерії приймання

Таблиця TTFT/TPOT/fairness для cold і reused prompts. Немає starving запитів, cache corruption після context edits або неконтрольованого VRAM peak. Startup FTW load поліпшення звітувати окремо від generation speed.
